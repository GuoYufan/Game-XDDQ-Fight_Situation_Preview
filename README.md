## 📖编译运行需知：解压后哪些目录需要放在指定路径（相对路径即可，无需绝对路径）
不需要放在指定路径。
解压后的目录就是项目目录。
项目需要的所有内容都已经在这同一个路径下了。

## 📖编译步骤
在编译器中选择编译选项“编译多个源代码文件”。
它会给出输入框，提示“输入源代码文件（相对路径，空格分隔）：”。
于是你把项目目录下的“源代码文件相对路径.txt”的文本内容复制粘贴进输入框。
然后点击“编译”。然后点击“运行”。即可。
运行时如果出现Segmentation fault，只要反复多次编译运行即可。

## 📖使用方法
一、在`src`目录下的文件`<双方初始信息.c>`里的
`void Fight_info_init(Fight_info * self, char *who)`

在这个名称为`Fight_info_init`的函数里选择参赛的PK双方是哪一组。

（可直接放置多组不同的PK双方放在其中。通过注释的取消与否来切换哪一组PK双方进行参赛。
如果取消注释的有多组，则只有最后一组PK双方可以参赛。）


二、在`src`目录下的文件`<双方初始信息.c>`里的
`void 当前对手(Fight_info *self, char *who)`

在这个名称为`当前对手`的函数（或任意名称前缀为`“当前对手”`的函数）里调整其中一组PK双方的初始信息。

每一组PK双方的初始信息是通过调用名称前缀为`“当前对手”`的函数来设置。可以编辑这些名称前缀为`“当前对手”`的函数来更改PK双方的指定初始信息，或自己新增一组新的PK双方。

这些“设置PK双方初始信息”的函数，不一定要每个都写满敌的全部初始信息与我的全部初始信息。除了我已经简化好的“开头统一部分与先行初始化”和“结尾统一部分”以外，也可以这样：
假设敌是信息固定，我的信息可变。
那么敌的初始信息可以单独写在一个函数里，随时调用即可。

void 某种固定初始信息设置(Fight_info *self)
{
    self->属性 = 初始数值;
}

if (who是敌) {某种固定初始信息设置(self)}
else {设置我}


三、主文件（主函数main函数在内）就是同目录下的文件`<main.c>`。
在编译器里编译后运行即可。
